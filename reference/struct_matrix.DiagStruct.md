# Matrix of a Diagonal Structure

The link applied entrywise, on the diagonal.

## Arguments

- s:

  A
  [`DiagStruct`](https://statmodels7.github.io/covstructs7/reference/DiagStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A diagonal positive definite matrix.
