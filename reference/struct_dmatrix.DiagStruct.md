# First Derivatives of a Diagonal Structure

Closed form from the link's own first derivative: the entries a free
value owns carry \\h'(\eta_k)\\ and everything else is zero.

## Arguments

- s:

  A
  [`DiagStruct`](https://statmodels7.github.io/covstructs7/reference/DiagStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named list of diagonal matrices.
