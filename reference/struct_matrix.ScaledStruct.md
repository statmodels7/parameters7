# Matrix of a Scaled Structure

The fixed matrix times the scale.

## Arguments

- s:

  A
  [`ScaledStruct`](https://statmodels7.github.io/covstructs7/reference/ScaledStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A symmetric positive semidefinite matrix.
