# Default First Derivatives

Fallback: one central difference of
[`param_value`](https://statmodels7.github.io/parameters7/reference/param_value.md)
per component (see
[`numerical_d1`](https://statmodels7.github.io/parameters7/reference/numerical_d1.md)).

## Arguments

- s:

  A
  [`parameter`](https://statmodels7.github.io/parameters7/reference/parameter.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named list of symmetric matrices.
