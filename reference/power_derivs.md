# Derivatives of a Power, for Composition

The four derivatives of \\r \mapsto r^{m}\\ at \\r\\, which vanish
beyond order \\m\\ because the power is a polynomial.

## Usage

``` r
power_derivs(r, m)
```

## Arguments

- r:

  The point.

- m:

  The exponent, a non-negative integer.

## Value

A list of four numbers.
