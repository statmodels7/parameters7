# Value of a Transition Matrix Parameter

Each row is the softmax of its own free values.

## Arguments

- s:

  A
  [`TransitionMatrixParam`](https://statmodels7.github.io/parameters7/reference/TransitionMatrixParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A \\K \times K\\ row-stochastic matrix.
