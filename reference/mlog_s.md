# The Symmetric Matrix Behind a Free Vector

Fills the lower triangle of \\S\\ with the free values and mirrors it.

## Usage

``` r
mlog_s(s, eta)
```

## Arguments

- s:

  A
  [`MatrixLogParam`](https://statmodels7.github.io/parameters7/reference/MatrixLogParam.md)
  object.

- eta:

  A numeric vector of free values.

## Value

A symmetric numeric matrix.
