# Log-Determinant Hessian of a Diagonal Structure

Closed form: \\m_k\\h''/h - (h'/h)^2\\\\ on the diagonal and zero
elsewhere, the entries being controlled independently unless the
structure shares one value, in which case there is only one free value.

## Arguments

- s:

  A
  [`DiagStruct`](https://statmodels7.github.io/covstructs7/reference/DiagStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
