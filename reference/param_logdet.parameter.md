# Default Log-Determinant

Fallback: the sum of the logs of the eigenvalues the declared rank
keeps, which is the log-determinant for a full-rank family and the log
pseudo-determinant otherwise.

## Arguments

- s:

  A
  [`parameter`](https://statmodels7.github.io/parameters7/reference/parameter.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A single number.
