# Log-Determinant Gradient of a Diagonal Structure

Closed form: \\m_k h'(\eta_k)/h(\eta_k)\\, with \\m_k\\ the number of
diagonal entries the free value owns – one, or the whole diagonal when
the structure shares a single value.

## Arguments

- s:

  A
  [`DiagStruct`](https://statmodels7.github.io/covstructs7/reference/DiagStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
