# Matrix of a Diagonal Parameter

The link applied entrywise, on the diagonal.

## Arguments

- s:

  A
  [`DiagMatrixParam`](https://statmodels7.github.io/parameters7/reference/DiagMatrixParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A diagonal positive definite matrix.
