# Free Vector of a Transition Matrix Parameter

The additive log-ratio of each row, exact; rejected when any row is
outside the open simplex or fails to sum to one.

## Arguments

- s:

  A
  [`TransitionMatrixParam`](https://statmodels7.github.io/parameters7/reference/TransitionMatrixParam.md)
  object.

- m:

  A \\K \times K\\ row-stochastic matrix.

- ...:

  Unused.

## Value

A named numeric vector of free values.
