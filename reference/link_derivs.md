# A Link's Inverse and Its Four Derivatives

The five-element list every chain in this package consumes: the link's
inverse at a free value and its first four derivatives.

## Usage

``` r
link_derivs(link, e)
```

## Arguments

- link:

  A linkfunctions7 link.

- e:

  A single free value.

## Value

A list of five numbers.

## See also

[`econ_scalars()`](https://statmodels7.github.io/parameters7/reference/econ_scalars.md),
which builds the same list for two links at once.
