# Name the Rows and Columns of a Parameter's Matrix

Applies the dimension labels every matrix a parameter produces carries.

## Usage

``` r
name_dims(m, s)
```

## Arguments

- m:

  A numeric matrix.

- s:

  A
  [`parameter`](https://statmodels7.github.io/parameters7/reference/parameter.md)
  object.

## Value

`m`, with dimnames.
