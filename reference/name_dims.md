# Name the Rows and Columns of a Structure's Matrix

Applies the dimension labels every matrix a structure produces carries.

## Usage

``` r
name_dims(m, s)
```

## Arguments

- m:

  A numeric matrix.

- s:

  A
  [`covstruct`](https://statmodels7.github.io/covstructs7/reference/covstruct.md)
  object.

## Value

`m`, with dimnames.
