# The Log-Determinant Terms of an AR(1) Parameter

The affine-logarithm terms of \\q(\rho) = (p-1)\log(1-\rho^2)\\, split
as \\(p-1)\\\log(1-\rho) + \log(1+\rho)\\\\ so that both pieces are
logarithms of affine functions.

## Usage

``` r
ar1_logdet_terms(s)
```

## Arguments

- s:

  An
  [`Ar1Param`](https://statmodels7.github.io/parameters7/reference/Ar1Param.md)
  object.

## Value

A list of numeric triples.
