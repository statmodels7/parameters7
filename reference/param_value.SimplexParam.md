# Value of a Simplex Parameter

The softmax point, named `p1..pK`.

## Arguments

- s:

  A
  [`SimplexParam`](https://statmodels7.github.io/parameters7/reference/SimplexParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A numeric vector of length \\K\\ summing to one.
