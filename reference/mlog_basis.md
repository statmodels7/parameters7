# The Basis Direction of One Free Value

The symmetric matrix \\\partial S / \partial \eta_k\\: a single diagonal
entry, or a symmetric pair below and above the diagonal.

## Usage

``` r
mlog_basis(s, k)
```

## Arguments

- s:

  A
  [`MatrixLogParam`](https://statmodels7.github.io/parameters7/reference/MatrixLogParam.md)
  object.

- k:

  The free-value index.

## Value

A symmetric numeric matrix.
