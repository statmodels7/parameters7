# Free Vector of a Diagonal Structure

The link applied in the forward direction to the diagonal, after
refusing a matrix that is not diagonal or not positive.

## Arguments

- s:

  A
  [`DiagStruct`](https://statmodels7.github.io/covstructs7/reference/DiagStruct.md)
  object.

- m:

  A diagonal positive definite matrix.

- ...:

  Unused.

## Value

A named numeric vector of free values.
