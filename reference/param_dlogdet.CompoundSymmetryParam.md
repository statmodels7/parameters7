# Log-Determinant Derivatives of a Compound Symmetry Parameter

Closed form at every order. The log-determinant is a sum of a function
of the scale and a function of the correlation, so every mixed component
is exactly zero.

## Arguments

- s:

  A
  [`CompoundSymmetryParam`](https://statmodels7.github.io/parameters7/reference/CompoundSymmetryParam.md)
  object.

- eta:

  A numeric vector of two free values.

- ...:

  Unused.

## Value

A named numeric vector.
