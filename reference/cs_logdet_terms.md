# The Log-Determinant Terms of a Compound-Symmetric Parameter

The affine-logarithm terms of \\q(\rho) = \log\\1 + (p-1)\rho\\ +
(p-1)\log(1-\rho)\\, the correlation's half of the log-determinant.

## Usage

``` r
cs_logdet_terms(s)
```

## Arguments

- s:

  A
  [`CompoundSymmetryParam`](https://statmodels7.github.io/parameters7/reference/CompoundSymmetryParam.md)
  object.

## Value

A list of numeric triples.
