# Log-Determinant Derivatives in the Weights

Evaluates the cyclic trace expansion for one tuple of weight indices.

## Usage

``` r
sum_struct_trace_term(minv, comp, t)
```

## Arguments

- minv:

  The inverse of the assembled matrix.

- comp:

  The list of components.

- t:

  An integer vector of weight indices, with repeats.

## Value

A single number.
