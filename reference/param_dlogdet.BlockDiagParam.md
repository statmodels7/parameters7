# Log-Determinant Derivatives of a Block-Diagonal Parameter

The blocks' own, concatenated at the first order and placed by owner
above it, every cross-block component being zero because the
log-determinant is a sum over the blocks.

## Arguments

- s:

  A
  [`BlockDiagParam`](https://statmodels7.github.io/parameters7/reference/BlockDiagParam.md)
  object.

- eta:

  A numeric vector of length `s@n_free`.

- ...:

  Unused.

## Value

A named numeric vector.
