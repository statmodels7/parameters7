# Second Derivative of a Scaled Structure

Closed form: \\h''(\eta) P\\.

## Arguments

- s:

  A
  [`ScaledStruct`](https://statmodels7.github.io/covstructs7/reference/ScaledStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named list with one symmetric matrix.
