# Row and Chart Coordinate of Each Free Value

The row each free value belongs to and its position inside that row's
chart, in the order the free vector uses.

## Usage

``` r
tm_positions(s)
```

## Arguments

- s:

  A
  [`TransitionMatrixParam`](https://statmodels7.github.io/parameters7/reference/TransitionMatrixParam.md)
  object.

## Value

A list with integer vectors `row` and `coord`.
