# Log-Determinant Gradient of a Diagonal Parameter

Closed form: \\m_k h'(\eta_k)/h(\eta_k)\\, with \\m_k\\ the number of
diagonal entries the free value owns – one, or the whole diagonal when
the parameter shares a single value.

## Arguments

- s:

  A
  [`DiagMatrixParam`](https://statmodels7.github.io/parameters7/reference/DiagMatrixParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
