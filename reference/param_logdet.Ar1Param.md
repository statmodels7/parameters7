# Log-Determinant of an AR(1) Parameter

Closed form: \\p\log\sigma^2 + (p-1)\log(1-\rho^2)\\, the determinant of
the correlation pattern being \\(1-\rho^2)^{p-1}\\.

## Arguments

- s:

  An
  [`Ar1Param`](https://statmodels7.github.io/parameters7/reference/Ar1Param.md)
  object.

- eta:

  A numeric vector of two free values.

- ...:

  Unused.

## Value

A single number.
