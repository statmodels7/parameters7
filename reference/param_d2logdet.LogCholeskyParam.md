# Log-Determinant Hessian of a Log-Cholesky Parameter

Closed form: zero, the log-determinant being linear.

## Arguments

- s:

  A
  [`LogCholeskyParam`](https://statmodels7.github.io/parameters7/reference/LogCholeskyParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector of zeros.
