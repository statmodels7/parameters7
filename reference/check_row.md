# One Row of a Diagnostic Table

One Row of a Diagnostic Table

## Usage

``` r
check_row(name, status, statistic = NA_real_)
```

## Arguments

- name:

  The name of the check.

- status:

  `"OK"`, `"FAIL"` or `"NOT CHECKED"`.

- statistic:

  The number the verdict rests on, or `NA`.

## Value

A one-row data frame.
