# The Pattern of a Compound-Symmetric Parameter

\\P(\rho) = I + \rho(J - I)\\ and its four derivatives in the free
value. The pattern is linear in the correlation, so every derivative is
the matching derivative of the correlation times the constant \\J - I\\.

## Usage

``` r
cs_pattern(s, sc)
```

## Arguments

- s:

  A
  [`CompoundSymmetryParam`](https://statmodels7.github.io/parameters7/reference/CompoundSymmetryParam.md)
  object.

- sc:

  The scalars of
  [`econ_scalars`](https://statmodels7.github.io/parameters7/reference/econ_scalars.md).

## Value

A list of five matrices.
