# Log-Determinant Gradient of a Log-Cholesky Parameter

Closed form: 2 in each diagonal direction and 0 elsewhere, since the
log-determinant is linear in the free vector.

## Arguments

- s:

  A
  [`LogCholeskyParam`](https://statmodels7.github.io/parameters7/reference/LogCholeskyParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
