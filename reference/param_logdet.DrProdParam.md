# Log-Determinant of a Scales-Times-Correlation Parameter

\\2\sum_j \log d_j + \log\lvert R \rvert\\, the scales contributing
twice because they multiply on both sides.

## Arguments

- s:

  A
  [`DrProdParam`](https://statmodels7.github.io/parameters7/reference/DrProdParam.md)
  object.

- eta:

  A numeric vector of length `s@n_free`.

- ...:

  Unused.

## Value

A single number.
