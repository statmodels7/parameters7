# Value of a Scales-Times-Correlation Parameter

Forms \\D R D\\ from the scales and the correlation block.

## Arguments

- s:

  A
  [`DrProdParam`](https://statmodels7.github.io/parameters7/reference/DrProdParam.md)
  object.

- eta:

  A numeric vector of length `s@n_free`.

- ...:

  Unused.

## Value

A symmetric matrix of side `s@dimension`.
