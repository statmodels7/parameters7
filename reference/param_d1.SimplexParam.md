# First Derivatives of a Simplex Parameter

Closed form: \\\partial_b \pi_a = \pi_a(\delta\_{ab} - \pi_b)\\, the
covariance structure of a categorical indicator.

## Arguments

- s:

  A
  [`SimplexParam`](https://statmodels7.github.io/parameters7/reference/SimplexParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named list of vectors of length \\K\\.
