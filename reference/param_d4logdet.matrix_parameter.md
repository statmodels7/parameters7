# Default Fourth Log-Determinant Derivatives

Fallback: one second-order stencil on
[`param_d2logdet`](https://statmodels7.github.io/parameters7/reference/param_d2logdet.md)
in the last two components of the tuple – one layer, mixed across
components where they differ.

## Arguments

- s:

  A
  [`matrix_parameter`](https://statmodels7.github.io/parameters7/reference/matrix_parameter.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
