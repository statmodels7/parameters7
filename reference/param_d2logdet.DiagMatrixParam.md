# Log-Determinant Hessian of a Diagonal Parameter

Closed form: \\m_k\\h''/h - (h'/h)^2\\\\ on the diagonal and zero
elsewhere, the entries being controlled independently unless the
parameter shares one value, in which case there is only one free value.

## Arguments

- s:

  A
  [`DiagMatrixParam`](https://statmodels7.github.io/parameters7/reference/DiagMatrixParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
