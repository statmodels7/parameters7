# Second Derivatives of a Diagonal Parameter

Closed form from the link's second derivative. The entries are
independent unless the parameter shares one value, so every cross pair
vanishes.

## Arguments

- s:

  A
  [`DiagMatrixParam`](https://statmodels7.github.io/parameters7/reference/DiagMatrixParam.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named list of diagonal matrices.
