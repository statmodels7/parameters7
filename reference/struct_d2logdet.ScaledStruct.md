# Log-Determinant Hessian of a Scaled Structure

Closed form: \\r\\h''/h - (h'/h)^2\\\\, which under the default log link
is zero, the log pseudo-determinant being linear in the free value.

## Arguments

- s:

  A
  [`ScaledStruct`](https://statmodels7.github.io/covstructs7/reference/ScaledStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
