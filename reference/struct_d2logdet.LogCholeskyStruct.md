# Log-Determinant Hessian of a Log-Cholesky Structure

Closed form: zero, the log-determinant being linear.

## Arguments

- s:

  A
  [`LogCholeskyStruct`](https://statmodels7.github.io/covstructs7/reference/LogCholeskyStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector of zeros.
