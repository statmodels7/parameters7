# Log-Determinant Gradient of a Scaled Structure

Closed form: \\r\\ h'(\eta)/h(\eta)\\, which under the default log link
is the rank itself, whatever the scale.

## Arguments

- s:

  A
  [`ScaledStruct`](https://statmodels7.github.io/covstructs7/reference/ScaledStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named numeric vector.
