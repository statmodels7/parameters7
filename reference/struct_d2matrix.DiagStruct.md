# Second Derivatives of a Diagonal Structure

Closed form from the link's second derivative. The entries are
independent unless the structure shares one value, so every cross pair
vanishes.

## Arguments

- s:

  A
  [`DiagStruct`](https://statmodels7.github.io/covstructs7/reference/DiagStruct.md)
  object.

- eta:

  A numeric vector of free values.

- ...:

  Unused.

## Value

A named list of diagonal matrices.
