# Log-Determinant of a Block-Diagonal Parameter

The sum of the blocks' log-(pseudo-)determinants, which is what the
determinant of a block-diagonal matrix is.

## Arguments

- s:

  A
  [`BlockDiagParam`](https://statmodels7.github.io/parameters7/reference/BlockDiagParam.md)
  object.

- eta:

  A numeric vector of length `s@n_free`.

- ...:

  Unused.

## Value

A single number.
